INFOMANCER SERVER - START HERE
=============================

You can run the InfoMancer setup helper even if you are not sure Docker is installed.
It checks Docker for you before changing InfoMancer.

InfoMancer Server requires:
- Docker Engine 24.0 or newer
- Docker Compose 2.20 or newer

If Docker is missing or too old, the helper will tell you what needs attention and
can open Docker's official installation/update instructions. On Windows, if winget
is available, the helper can also offer to install or update Docker Desktop.

WINDOWS
Double-click: Setup-InfoMancer.cmd

MAC
Double-click: Setup-InfoMancer.command
If macOS blocks it, right-click the file and choose Open.

LINUX
Open Terminal in this folder and run:
  ./setup-infomancer.sh

The helper will ask where your Movies and TV Shows are.
Then it will start InfoMancer and print:
- the address to open
- the one-time setup code for the first Librarian account

It does not move or copy your media files.
