INFOMANCER SERVER - START HERE
=============================

Before you start:
Install Docker and make sure it is running.

WINDOWS
Double-click: Setup-InfoMancer.cmd

MAC
Double-click: Setup-InfoMancer.command
If macOS blocks it, right-click the file and choose Open.

LINUX
Open Terminal in this folder and run:
  ./setup-infomancer.sh

The helper will ask where your Movies and TV Shows are.
Then it will start InfoMancer and print:
- the address to open
- the one-time setup code for the first Librarian account

It does not move or copy your media files.
