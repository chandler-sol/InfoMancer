ABOUT

InfoMancer

A local-first media catalog for understanding, matching, and carefully organizing the Movies and TV Shows you already own.

Version {{ app_version }} Build local

LOCAL FIRST

Your library stays yours

InfoMancer catalogs files where they already live. It does not provide media, host your collection, or require your library to be uploaded to a cloud service.

CAREFUL BY DEFAULT

Review before changing

Scans read the library without renaming it. Filename and folder changes are previewed and require explicit approval before InfoMancer applies them.

BUILT FOR COLLECTIONS

Movies and TV, accounted for

Search across storage, resolve metadata matches, identify missing episodes, and prepare consistent Plex-compatible names from one catalog.
