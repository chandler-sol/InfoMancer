ACCOUNT RECOVERY

Get back into InfoMancer

Local accounts are recovered by your installation’s Librarian. InfoMancer never sends your password or stores a readable copy of it.

Choose the situation that applies

Another Librarian can sign in

Ask them to open Profile → Users and create a password-reset link for your account.

No Librarian can sign in

Someone with terminal access to the InfoMancer server must generate a single-use recovery link.

python -m app.cli recovery-link USERNAME --base-url https://your-infomancer-address

Docker installations run this command inside the main infomancer container. The Help page contains the complete command.
