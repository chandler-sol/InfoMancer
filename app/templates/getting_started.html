Get a project API key

The API key identifies the app or project asking TheTVDB for metadata. For this self-hosted build, register a key for your InfoMancer installation.

  1. Create or sign in to your TheTVDB account.
  2. Open API and Data Licensing, then choose Get Started.
  3. Register your self-hosted InfoMancer project and copy its API key.
  4. Paste the key here. Add a PIN only if TheTVDB says your access model requires one.
