Select a recovery package created by InfoMancer. The next screen verifies every declared file and shows the package contents before any live data is changed.

SAFETY MODEL

What restore does

  • Verifies the package and staged database before touching the live installation.
  • Creates a fresh, self-verified portable safety backup of the current database and collection artwork.
  • Restores the catalog database and collection artwork together with automatic rollback if commit fails.
  • Never restores provider credentials, provider-secret encryption keys, deployment environment files, media files, or application binaries.

After a reinstall, restore the portable package first, then re-enter provider credentials and confirm that the same media paths or shares are available.
