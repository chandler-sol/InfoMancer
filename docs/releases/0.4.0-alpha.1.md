# InfoMancer 0.4.0 Alpha 1

InfoMancer 0.4 is an early testing release focused on safer administration,
better library navigation, and the foundations needed to grow from a media
catalog into an explainable media-analysis platform.

## Highlights

- Create Collections with custom artwork and manually ordered movies, series,
  and individual episodes.
- Save movies, series, and episodes as Favorites, including an optional note
  explaining why an episode was saved.
- Browse redesigned Home, library, collection, and favorites experiences on
  desktop and mobile.
- Search local titles and people with faster fuzzy suggestions and keyboard
  navigation.
- Inspect runtime, resolution, codecs, bitrate, container, and HDR/SDR details
  with clearer explanations for files that cannot be read.
- Use improved bulk and individual matching flows, return-to-library
  navigation, localized TVDB titles and artwork selection.
- Export and import portable application settings without copying accounts,
  secrets, sources, or media.
- Create, download, validate, and restore complete SQLite database backups.
- Check GitHub releases, including alpha prereleases, and optionally apply
  updates through a restricted host-side helper with health checks and rollback.
- Use clearer account recovery, source management, setup, logs, diagnostics,
  confirmations, and plain-language errors.

## Alpha cautions

- Back up the database before testing upgrades, restores, bulk matching, or
  filesystem changes.
- Matching, renaming, and restoration operations should be reviewed before
  approval.
- Automatic installation from the interface requires the optional host updater
  documented in `docs/UPDATES.md`.
- This remains alpha software. Database and interface behavior may change
  before the first stable release.

## Planned direction: Media Intelligence Engine

The next major development direction is the Media Intelligence Engine (MIE):
an explainable assessment system that observes media facts, reasons from
evidence, advises the user without silently changing files, and learns from
explicit corrections and preferences.

Planned modules include:

- a unified Library Health dashboard and prioritized findings;
- evidence-backed identity confidence and multi-episode-file detection;
- exact duplicate and storage-recovery analysis;
- quality and consistency assessments using user-controlled preferences;
- franchise, sequel, special, spin-off, and timeline relationships;
- library-health category scores with transparent calculations;
- change tracking and recommendations that always explain their evidence.

These items describe the intended roadmap, not features promised or completed
in this alpha release.
