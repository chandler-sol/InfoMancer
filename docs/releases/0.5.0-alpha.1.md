# InfoMancer 0.5.0 Alpha 1

InfoMancer 0.5 begins the transition from media catalog to explainable media
intelligence.

## Highlights

- Introduces the first Media Intelligence Engine library-health analysis.
- Redesigns the dashboard, navigation, task feedback, and responsive library UI.
- Adds clearer findings with severity, evidence, and recommended next actions.
- Improves local search, filtering, suggestions, and person discovery.
- Expands the guided tour with contextual highlights and a simulated scan.
- Improves local account recovery, session handling, and Librarian administration.

## Alpha notice

This is an early testing release. Back up the InfoMancer database before updating
an important library, review every proposed filesystem change, and report any
unexpected analysis or matching behavior with the relevant diagnostic logs.
