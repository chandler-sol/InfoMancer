# InfoMancer 0.5.0-alpha.2

This testing alpha advances the Media Intelligence Engine while preserving InfoMancer's review-first, local-first behavior.

## New

- Duplicate Review search, source filtering, recoverable-space sorting, and safe bulk review actions.
- Identity Intelligence reports with provider, title, year, and catalog-placement confidence evidence.
- Storage Intelligence dashboard for source and media-type usage, largest titles and folders, cleanup history, managed Trash, and reclaimed duplicate space.
- Database backup verification and privacy-conscious diagnostic bundles.
- Alpha testing checklist for cross-platform friend testing.

## Safety

- Bulk duplicate actions classify or verify candidates only; they do not delete media.
- Identity recommendations explain conflicts and never apply changes automatically.
- Diagnostic bundles exclude credentials, sessions, provider secrets, and the media database.

## Alpha validation

- 105 automated tests pass on the Windows development environment.
- Python dependency consistency and release-package creation pass.
- Bandit reports no high-severity findings. Its medium findings are retained for
  ongoing review; most concern parameterized SQL assembled from fixed clauses or
  fixed HTTPS dataset endpoints rather than interpolated user values.
- Windows, macOS, Ubuntu, and Debian friend-testing remains explicitly tracked
  in `docs/CROSS_PLATFORM_ALPHA_MATRIX.md`; those platforms are not claimed as
  supported until the matrix is completed on each one.
