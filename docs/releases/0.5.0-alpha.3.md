# InfoMancer 0.5.0-alpha.3

This testing alpha expands media integrity analysis and makes everyday library organization easier while preserving InfoMancer's local-first, review-before-change behavior.

## New

- Configurable background file fingerprinting with automatic, scheduled, on-demand, and disabled modes.
- Persistent fingerprint state and clearer Duplicate Review verification progress.
- Library-style cover cards on Favorites and collection detail pages, with direct favorite and management controls.
- Account-based recent search history with autocomplete integration and a clear-history action.
- Richer title headers with personal organization, available synopsis, credits, and compact library facts.

## Improved

- Favorite confirmation banners now name the affected title and survive anchored cover-card redirects.
- Cover-card action hover delay is shorter.
- Global search results match the search-field width.
- Duplicate and storage intelligence messaging provides clearer status and recovery context.
- The README hero image and heading are refreshed for the current interface.

## Safety

- Duplicate review continues to compare evidence and recommend the stronger copy without deleting media automatically.
- Fingerprinting is read-only and can pause around other background activity.
- Favorites, collections, tags, ratings, and search history remain scoped to the signed-in account where applicable.

## Alpha validation

- 110 automated tests pass on the Windows development environment.
- Python compilation and release diff checks pass.
- Windows, macOS, Ubuntu, and Debian friend-testing remains tracked in `docs/CROSS_PLATFORM_ALPHA_MATRIX.md` and is not claimed complete until each environment is verified.
