# InfoMancer 0.6.0-alpha.1

## Smart Collections

- Saved dynamic filters cover genre, release year, resolution, HDR/SDR or high-bitrate quality, source, account favorites, missing episodes, and active Library Health categories.
- A live cover preview shows matches before saving. Smart Collections recalculate from the current catalog whenever opened and remain separate from manually ordered Collections.

## Metadata maintenance

- Metadata Settings now reports provider configuration, 30-day freshness, missing artwork, identifiers, and credits.
- Selected titles or stale records can be queued for incremental IMDb/TVDB refresh without discarding existing metadata when a provider fails.
- Persistent per-title status, attempts, provider results, errors, retry controls, and task progress make failures visible and recoverable.
- Library Health now flags missing artwork, credits, provider identifiers, episode data, and stale metadata.

## Activity and notifications

- The account activity center now includes scan, Source Guard, fingerprinting, duplicate verification, metadata refresh, and new Library Health finding events.
- Each event retains per-account read state and links to the affected title, source, task area, collection, custom library, or finding.

## Mobile organization and navigation

- Title organization now opens as an animated, accessible overlay during normal browsing while retaining a standalone page for direct links and fallback navigation.
- The mobile background-activity control is now a compact status dot: pulsing green while work is running, solid green when attention is available, and dimmed while idle.
- Footer links use a quieter neutral treatment, with clear hover and keyboard-focus feedback.
- Mobile overlays and sticky controls account for device safe areas.

## Custom Libraries

- Librarians can create Movie, TV Show, or mixed custom libraries and browse them with the normal cover interface.
- Movies and series can belong to multiple custom libraries. The new **Add to Libraries** action supports checkbox selection and inline library creation without copying or moving media files.
- Episode-level menus add the parent series to custom libraries; Collections remain the place for organizing individual episodes.

## Deprecated

- Custom installation names are deprecated. InfoMancer now uses its product name and logo consistently in the header, browser titles, setup flow, and settings. Existing stored and imported installation-name values remain readable during the compatibility period but are no longer displayed or editable.
