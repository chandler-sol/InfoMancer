# InfoMancer 0.6.0-alpha.2

## Sort Titles and library organization

- Account-specific Sort Titles now control alphabetical placement without changing displayed title names.
- Alphabetical browsing ignores leading `A`, `An`, and `The` unless an account Sort Title overrides the title.
- Cover view supports ordered multi-selection and an animated **Append Sort Titles** workflow with shared prefixes, padded or plain numbering, and optional `a` through `z` suffixes.
- The reorder dialog includes a larger drag handle, animated row movement, precise up/down controls, and reduced-motion support.
- Account library exports now include Sort Titles.

## Cover-library refinements

- Cover selection provides persistent green checks, a floating batch-action bar, and a **Deselect all** action.
- Selected covers no longer retain the dimmed action overlay, and cover controls remain beneath sticky headers while scrolling.
- Cover columns distribute across the available width, while alphabet, view, and cover-size controls share a responsive toolbar.
- The All, Movies, and TV Shows selectors have larger targets.

## Organization overlays

- **Add to Libraries**, **Organize & Tags**, and bulk Sort Titles use the shared animated overlay while retaining direct-page fallbacks.
- Tag creation copy now makes it clear that new tags are immediately applied to the title.
- The organization action now uses the concise **Save Changes** label.

## Compatibility

- Existing numeric custom-order values remain stored for compatibility, but new organization uses Plex-style account Sort Titles.
