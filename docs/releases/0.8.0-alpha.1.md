# InfoMancer 0.8.0-alpha.1

InfoMancer 0.8 is the first release line built around the unified Workspace architecture. This alpha is intended for qualification and hands-on testing before Beta promotion.

## Highlights

- Unified Library workspace for Movies and TV Shows with List and Covers views, density controls, Saved Views, favorites, ratings, tags, Collections, Smart Collections, and Custom Libraries.
- Library Inspector for metadata, technical media facts, organization, matching state, episode/file detail, and title-level actions without losing Library context.
- Unified Review workspace for Media Intelligence findings, duplicate candidates, unmatched media, missing episodes, metadata/quality issues, and persisted rename proposals.
- Media Intelligence Engine with evidence-backed findings and recommendations instead of opaque health scoring.
- Operation History with guarded Safe Undo for supported filesystem-changing operations.
- Preview-first rename and season-folder organization workflows.
- Managed Trash, duplicate verification, guarded restore, and Read-Only / Standard / Lockdown filesystem protection modes.
- Source Guard behavior intended to preserve catalog state when storage is unavailable or a scan fails.
- Scheduled fingerprinting and Managed Trash maintenance controls.
- Portable recovery packages, database backup/restore, and export tooling.
- Librarian and Member accounts, sessions, invitations, recovery, local authentication, and optional Cloudflare Access integration.
- Global search, recent account-synced searches, command palette, responsive navigation, and the rebuilt role-aware onboarding tour.
- Docker deployment plus preview native desktop packaging.

## Desktop preview packages

This draft release is expected to include native preview packages for Windows, macOS, and Linux built from the same commit as the server/source package.

- Windows: NSIS installer preview.
- macOS: DMG preview. The current alpha package is not Apple-notarized and may require the normal macOS override flow for unsigned development software.
- Linux: DEB and AppImage previews.

The native desktop shell bundles a local InfoMancer core and can also connect to a remote InfoMancer server. Desktop packaging remains alpha-quality and should be treated as test software.

## Server / self-hosted package

The release ZIP is credential-free and contains the FastAPI application, Docker/deployment files, documentation, scripts, and tests needed for a self-hosted installation. Local databases, logs, caches, secrets, and provider credentials are intentionally excluded.

## Alpha qualification notes

0.8 is not yet Stable. Testing should continue to focus on:

- filesystem edge cases, source disconnects, permissions, collisions, and state drift;
- backup, recovery, interrupted operations, and disk-full behavior;
- large-library performance and network-storage behavior;
- mobile/responsive behavior, accessibility, keyboard operation, and reduced motion;
- native installer/update behavior on clean machines;
- authorization boundaries, diagnostics, secret redaction, and release integrity.

Filesystem-changing operations should continue to be tested with backups available. Read-Only Mode is recommended when evaluating catalog and analysis behavior without permitting media-file changes.

## Integrity

Release assets are accompanied by SHA-256 checksums generated by the release workflow.
