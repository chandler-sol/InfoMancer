# InfoMancer 0.8.1-alpha.1

InfoMancer 0.8.1-alpha.1 is a cleanup and hardening pass on the 0.8 alpha line, built from the `release/0.8.1-alpha.1` branch. It carries no new features; every change is either a security improvement or a structural simplification verified by the full test suite.

## Security hardening

- The middleware Content-Security-Policy now mirrors the per-request template nonce, so template-rendered pages are strict at both the header and meta layer instead of relying on a permissive `'unsafe-inline'` fallback. Non-template responses keep the legacy fallback.
- Added `object-src 'none'` to the header-level CSP to match the meta policy.
- Multipart upload submissions now reject non-success responses instead of replacing the whole application view with an error page.

## Maintenance and reliability

- Background scheduler lifecycle migrated from deprecated FastAPI `on_event` hooks to lifespan handlers; boot-time deprecation warnings removed.
- Consolidated fragmented override stylesheets: Library selection (3 files → 1), mobile chrome (3 files → 1), and review queue polish folded into its base stylesheet — with cascade order preserved exactly.
- Retired `-polish` asset naming in favor of owner-named stylesheets (`dialog-controls`, `library-controls`, `detail-page`, `library-saved-views`, `organize-bulk`, `recovery-restore`, `onboarding-tour-mobile`).
- Fixed a flaky CLI recovery-link test assertion.

## Desktop preview packages

Native preview packages are built from the same commit as the server/source package:

- Windows x64: NSIS installer preview, `InfoMancer_0.8.1-alpha.1_x64-setup.exe`.
- macOS Apple silicon: DMG preview, `InfoMancer_0.8.1-alpha.1_aarch64.dmg`. Not notarized; use the normal macOS override flow for unsigned development software.
- Linux x86-64: DEB and AppImage previews.

The native desktop shell bundles a local InfoMancer core and can also connect to a remote server. The 0.8 native preview does not yet bundle FFprobe; install FFmpeg/FFprobe on the host for technical media inspection. Desktop packaging remains alpha-quality test software.

## Qualification notes

This build is intended for regression testing of the cleanup itself: Library selection styling, mobile layouts, dialog chrome, review queue density, and upload flows. Filesystem-changing operations should continue to be tested with backups available.

## Integrity

Release assets are accompanied by SHA-256 checksums generated by the release workflow.
