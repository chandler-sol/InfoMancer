# InfoMancer 0.8.1-beta.2

InfoMancer 0.8.1-beta.2 continues the 0.8.1 beta test line with packaged-desktop reliability fixes, clearer recovery feedback, and additional UI/accessibility polish. The beta.2 label is intentionally retained while this test line is iterated; not every internal beta build is assigned a new beta number.

## Packaged desktop reliability

- Bundled desktop builds now include and use a reliable CA certificate store for packaged HTTPS requests.
- Intel macOS packaging has additional Ventura compatibility checks and hardened native dependency handling.
- Packaged macOS core startup is smoke-tested before release assets are accepted.
- Desktop package and launcher version stamping is kept aligned with the beta.2 test line.

## Activity and recovery

- Activity errors are presented in more actionable, human-readable form.
- Recovery details and retry controls have clearer styling and placement.
- Metadata retry actions remain available from Metadata Settings.

## Metadata matching

- Bulk TV matching now distinguishes provider failures from genuine no-match results.
- TV series matching surfaces TVDB provider failures more clearly instead of presenting them as missing matches.
- Packaged HTTPS fixes improve reliability of metadata-provider requests from native desktop builds.

## Display and usability

- Added display/accessibility refinements for desktop UI scaling.
- Long poster titles are clamped so they do not stretch card rows, with the complete title available on hover.
- Password visibility controls received additional behavior and UI cleanup.

## Install 0.8.1 beta.2

Choose the file that matches your computer:

- **Windows 10/11 x64:** `InfoMancer-0.8.1-beta.2-Windows-x64-Setup.exe`
- **Mac with Intel:** `InfoMancer-0.8.1-beta.2-macOS-Intel.dmg`
- **Mac with Apple Silicon:** `InfoMancer-0.8.1-beta.2-macOS-Apple-Silicon.dmg`
- **Debian / Ubuntu / Linux Mint x86-64:** `InfoMancer-0.8.1-beta.2-Linux-x86_64.deb`
- **Other Linux x86-64 desktops:** `InfoMancer-0.8.1-beta.2-Linux-x86_64.AppImage`
- **Docker / server:** `InfoMancer-0.8.1-beta.2.zip`

Native packages offer two choices at launch:

- **Run on this computer** creates a standalone local InfoMancer installation.
- **Connect to a server** opens an InfoMancer server that is already running elsewhere.

> **Important:** In 0.8, a standalone native installation is local-only. **Run on this computer does not turn that desktop into a remotely available InfoMancer server.** Use the server deployment when multiple computers need to share one catalog.

Native packages bundle the FFprobe component used for technical media inspection. A separate system FFmpeg installation is not required for the packaged desktop app.

Windows beta packages are not yet Authenticode-signed, and macOS beta packages are not yet Apple-notarized. Download only from the official InfoMancer release and use `SHA256SUMS.txt` to verify a package when desired.

See **[Install InfoMancer](../INSTALLATION.md)** for the short platform-by-platform setup guide.

## Qualification notes

This beta is intended for cross-platform regression testing of the current 0.8.1 code line, especially native startup, packaged HTTPS/provider access, metadata matching feedback, display scaling, mapped/network storage, FFprobe-backed inspection, and desktop install/uninstall behavior. Filesystem-changing operations should continue to be tested with backups available.

## Integrity

Release assets are accompanied by SHA-256 checksums generated by the release workflow.


## Second-pass desktop cleanup

- Fixed the Linux bundled core surviving after the desktop launcher closes.
- Improved signed desktop-update messaging while keeping startup independent of Internet access.
- Added an in-place TVDB credential editor to Metadata Settings.
- Removed outgoing-page navigation cover/fade behavior that could cause desktop UI popping.
- Tightened Linux desktop/AppStream identity checks and persistent launcher diagnostics.
- Consolidated Beta 2 packaging back onto the canonical cross-platform release workflow.
